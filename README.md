# Student Marks Analysis Using NumPy

## 📌 About the Project

This project is about analyzing student marks using Python and the NumPy library. I used NumPy functions to calculate different statistical values from a list of student marks.

## 🎯 Objective

The main objective of this project is to learn how to use NumPy for basic numerical calculations and data analysis.

## 🛠️ Tools Used

* Python
* Jupyter Notebook
* NumPy

## 📊 Features

* Calculate the total marks
* Calculate the mean (average)
* Find the median
* Find the minimum marks
* Find the maximum marks
* Calculate the standard deviation
* Display a summary of the marks

## 💻 NumPy Functions Used

* `np.sum()` – Calculates the total.
* `np.mean()` – Calculates the average.
* `np.median()` – Finds the middle value.
* `np.min()` – Finds the smallest value.
* `np.max()` – Finds the largest value.
* `np.std()` – Calculates the standard deviation.

## ▶️ How to Run

1. Open the Jupyter Notebook.
2. Import the NumPy library.
3. Create a list of student marks.
4. Run the code cells one by one.
5. View the calculated results.
